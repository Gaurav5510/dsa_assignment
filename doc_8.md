Question 8 Documentation

(a) Data Structures
• Array is used to store random numbers
• Global variables:
• comparisons – counts number of comparisons
• swaps – counts number of swaps

(b) Sorting Algorithms Implemented

• Bubble Sort
• Repeatedly compares adjacent elements
• Swaps if out of order

• Selection Sort
• Finds smallest element in each pass
• Places it in correct position

• Insertion Sort
• Inserts each element into correct position
• Shifts larger elements
• Merge Sort
• Divide and conquer approach
• Recursively divides array
• Merges sorted halves

(c) Main Method Organization
• Ask user to enter N
• Generate N random numbers between 1 and 1000
• Display generated numbers
• Show menu for sorting algorithm
• Perform selected sorting
• Display sorted numbers
• Print total comparisons
• Print total swaps (if applicable)

(d) Sample Output

Explanation
• Program first generates random numbers.
• User selects sorting algorithm.
• Chosen algorithm sorts the array.
• Comparisons and swaps are counted.
• Merge sort uses divide and conquer method.
• This program helps compare performance of sorting algorithms.
